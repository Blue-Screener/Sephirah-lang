# Sephirah语言手册

## 简介

Sephirah是由BlueScreener在2026年8月开发的一门Esolang，类似Brainfxxk，但语法更加复杂而难以理解。

## 纸带、单元格、指针

Sephirah类似Brainfxxk，使用一个列表存储数据。不同的是，Sephirah使用称为“**纸带**”**（Tape）**的动态列表，可以向左或向右无限扩展。

纸带上划分出一个个**单元格（Cell）**，在程序开始时，纸带上只有一个单元格。单元格可以存储**数字**或**Sephirah**（见下文）。数字为单字节有符号整数，范围**-128~127**，会自动上溢或下溢。

有一个**指针（Pointer）**指向单元格，可以向左/向右移动。指针移动时如果触及到纸带的左右边界，纸带会**自动扩展**出新的单元格。

## 行、移动指令

Sephirah的代码分为若干**行（Line）**，每行的结尾须换行。

在Sephirah中有三种移动指令，能够移动指针，分别为`.`（原地移动）、`<`（左移一格）和`>`（右移一格）。

每行中必须**有且只有一个**移动指令，否则会出现报错：

```
Error running Sephirah code, line 1: This line has no or too many "." "<" or ">" command.
```

每次移动（包括使用移动指令/Sephirah移动指针）之后，如果移动到的新单元格中为Sephirah，则需要**立即执行**该Sephirah。

## Sephirah

Sephirah语言的指令分为两种：上文介绍的**移动指令**、以及**Sephirah**。Sephirah共有10个，名称来源于神秘学概念“卡巴拉生命之树”中的十个”质点“（Sephirah）。

Sephirah的功能是操作单元格中的数据和/或移动指针，以下是十个Sephirah（编号为0~9）的功能：

0. **Sephirah “`0`”**：表示本行开始/程序中止。每一行代码都需要以Sephirah “`0`”开始，否则将被视为注释。如果Sephirah “`0`”出现在不是行首的位置，程序将中止运行。
1. **Sephirah “`+`”**：若本格是数字，将本格加1。
2. **Sephirah “`^`”**：若本格是数字，转换为Sephirah。
3.	**Sephirah “`v`”**：若本格是Sephirah，转换为数字。
4. **Sephirah “`(`”**：循环开始标记。
5. **Sephirah “`)`”**：若本格不是0也不是Sephirah “`0`”，跳转至上一个Sephirah “`(`”所在的行。
6. **Sephirah “`g`”**：若本格是数字，则向右跳「本格的数字」格（如果是负数则实际效果为向左跳）。
7. **Sephirah “`a`”**：若本格是非负数，则输出该数字对应的ASCII字符。
8. **Sephirah “`-`”**：若本格是正数，将左侧格加上本格的相反数；若本格是负数，将右侧格加上本格的相反数；然后将本格归零。
9. **Sephirah “`n`”**：若本格是数字，将本格加上当前的纸带长度（即纸带包含的单元格数量）。

注意事项：

- 如果某个Sephirah需要获取数字，但单元格内是一个Sephirah，就会出现报错：
	```
	Error running Sephirah code, line 1: Expected a number instead of a Sephirah.
	```

- Sephirah “`^`”将一个数字转换为Sephirah时，根据数字的个位数转换为对应的Sephirah。例如，如果格中数字为`67`，使用`^`后会转换成编号为7的Sephirah，也就是`a`。然而，原来的数据`67`实际上**并没有被抹去**，如果对这个单元格再次使用`v`，Sephirah “`a`”就会恢复成`67`，而不是`7`。

- 当使用Sephirah “`)`”跳转时，会跳转到上一个Sephirah “`(`”所在行的**行首**。因此`(`在一行中具体处于什么位置对运行结果实际上没有影响。如果Sephirah “`)`”前没有对应的“`(`”，就会出现报错：
	```
	Error running Sephirah code, line 1: Sephirah ")" has nowhere to go.
	```

- Sephirah “`g`”是唯一一个涉及到移动指针的Sephirah，它会让指针直接跳到目标格。这意味着，如果在当前格和目标格之间的单元格中储存着一些Sephirah，中间的这些Sephirah不会被执行。

- 如果让Sephirah “`a`”获取了一个负数，并不会出现报错，解释器会直接忽略。

## 注释

正如先前提到的，如果某一行不以Sephirah “`0`”开头，本行会被自动识别为注释。

如果要实现行内注释，使用一个分号。

## 解释器

Sephirah程序的默认扩展名为`.seph`，通过一个Python实现的解释器来运行。

在程序的第一行可以加入**运行选项**，分为两种：

- **调试模式**：在程序第一行写`debug`以开启调试模式。执行时，解释器会输出每一步运行的行、纸带状态、指针位置和输出内容。使用`debugout`可以将调试信息输出至文件。
- **长纸带报警模式**：在程序第一行写`ltw`（Lont Tape Warning）以开启长纸带报警模式。开启后，如果使用的纸带过长，解释器会强行中止程序，帮助开发者**节约用纸，保护环境**。有五个不同的阈值（单元格数量）可选：`ltw16` `ltw32` `ltw64` `ltw128` `ltw256`；如果仅仅输入`ltw`，默认使用`ltw64`。
