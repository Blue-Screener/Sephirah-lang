# Sephirah语言手册

## 简介

Sephirah是由BlueScreener在2026年8月开发的一门Esolang，类似Brainfxxk，但语法更加复杂而难以理解。

## 纸带、单元格、指针

Sephirah类似Brainfxxk，使用一个列表存储数据。不同的是，Sephirah使用称为**“纸带”（Tape）**的双端队列，可以向左或向右无限扩展。

纸带上划分出一个个**单元格（Cell）**，在程序开始时，纸带上只有一个单元格。单元格可以存储**数字**或**Sephirah**（见下文）。数字为单字节有符号整数，范围**-128~127**，会自动上溢或下溢。

每个单元格的初始值为数字0。

有一个**指针（Pointer）**指向单元格，可以向左/向右移动。指针移动时如果触及到纸带的左右边界，纸带会**自动扩展**出新的单元格。

## 行、移动指令

Sephirah的代码分为若干**行（Line）**，每行的结尾须换行。

在Sephirah中有三种移动指令，能够移动指针，分别为`.`（原地移动）、`<`（左移一格）和`>`（右移一格）。

每行中必须**有且只有一个**移动指令，否则会出现报错：

```
Error running Sephirah code, line 1: This line has no or too many "." "<" or ">" command.
```

每次移动（包括使用移动指令/Sephirah移动指针）之后，如果移动到的新单元格中为Sephirah，则需要**立即执行**该Sephirah。

## Sephirah

Sephirah语言的操作符分为两种：上文介绍的**移动指令**、以及**Sephirah**。Sephirah共有10个，名称来源于神秘学概念“卡巴拉生命之树”中的十个”质点“（Sephirah)。

Sephirah的功能是操作单元格中的数据和/或移动指针，以下是十个Sephirah（编号为0~9）的功能：

0. **Sephirah “`0`”**：表示本行开始/程序中止。每一行代码都需要以Sephirah “`0`”开始，否则将被视为注释。如果Sephirah “`0`”出现在不是行首的位置，程序将中止运行。
1. **Sephirah “`+`”**：若当前单元格是数字，将当前单元格加1。
2. **Sephirah “`^`”**：若当前单元格是数字，转换为Sephirah。
3.	**Sephirah “`v`”**：若当前单元格是Sephirah，转换为数字。
4. **Sephirah “`(`”**：循环开始标记。
5. **Sephirah “`)`”**：若当前单元格不是0也不是Sephirah “`0`”，跳转至上一个Sephirah “`(`”所在的行。
6. **Sephirah “`g`”**：若当前单元格是数字，则向右跳「当前单元格的数字」格（如果是负数则实际效果为向左跳）。
7. **Sephirah “`a`”**：若当前单元格是非负数，则输出该数字对应的ASCII字符。
8. **Sephirah “`-`”**：若当前单元格是正数，将左侧格加上当前单元格的相反数；若当前单元格是负数，将右侧格加上当前单元格的相反数；然后将当前单元格归零。
9. **Sephirah “`n`”**：若当前单元格是数字，将当前单元格加上当前的纸带长度（即纸带包含的单元格数量）。

注意事项：

- 运行纸带上的Sephirah “`0`”时，什么都不会发生。

- 如果某个Sephirah需要获取数字，但单元格内是一个Sephirah，就会出现报错：
	```
	Error running Sephirah code, line 1: Expected a number instead of a Sephirah.
	```

- Sephirah “`^`”将一个数字转换为Sephirah时，根据数字的个位数转换为对应的Sephirah。例如，如果当前单元格中数字为`67`，使用`^`后会转换成编号为7的Sephirah，也就是`a`。然而，原来的数据`67`实际上**并没有被抹去**，如果对这个单元格再次使用`v`，Sephirah “`a`”就会恢复成`67`，而不是`7`。

- 当使用Sephirah “`)`”跳转时，会跳转到上一个Sephirah “`(`”所在行的**行首**。因此`(`在一行中具体处于什么位置对运行结果实际上没有影响。如果Sephirah “`)`”前没有对应的“`(`”，就会出现报错：
	```
	Error running Sephirah code, line 1: Sephirah ")" has nowhere to go.
	```

- Sephirah “`g`”是唯一一个涉及到移动指针的Sephirah，它会让指针直接跳到目标格。这意味着，如果在当前格和目标格之间的单元格中储存着一些Sephirah，中间的这些Sephirah不会被执行。

- 如果让Sephirah “`a`”获取了一个负数，并不会出现报错，解释器会直接忽略。

## 注释

正如先前提到的，如果某一行不以Sephirah “`0`”开头，本行会被自动识别为注释。

如果要实现行内注释，使用一个分号。

## 解释器

Sephirah程序的默认扩展名为`.seph`，通过一个Python实现的解释器来运行。

在程序的第一行可以加入**运行选项**，分为两种：

- **调试模式**：在程序第一行写`debug`以开启调试模式。执行时，解释器会输出每一步运行的行、纸带状态、指针位置和输出内容。调试模式有几种子模式：
	- `debug`：仅在控制台输出运行状态；
	- `debuglog`：仅在文件中输出运行状态；
	- `debugout`：在控制台输出运行状态，并同步输出至文件；
	- `mrkonly`：可以加在任意的模式之后。加入后不会输出每一行的状态，仅在代码中标记mrk处输出。
- **长纸带报警模式**：在程序第一行写`ltw`（Lont Tape Warning）以开启长纸带报警模式。开启后，如果使用的纸带过长，解释器会强行中止程序，帮助程序员**节约用纸，保护环境**。有五个不同的阈值（单元格数量）可选：`ltw16` `ltw32` `ltw64` `ltw128` `ltw256`；如果仅仅输入`ltw`，默认使用`ltw64`。

### XKCD Random Number


## Sephirah扩展

**Sephirah扩展**是Sephirah语言的扩展，加入了更多特性。主要的新增功能包括：

- 改善报错信息，保护程序员心理健康；
- 增加新的操作符，使得编程更加便利。

Sephirah扩展目前尚未实现。

### 新的运行选项

在程序的第一行加入**`ext`运行选项**可以启用Sephirah扩展。启用后可以使用新的运行选项：

- `please`：该选项可以将程序的报错信息变得**更加友善**，有助于程序员的心理健康。
- `happy`：启用该选项后，解释器一旦遇到错误将**不再报错，而是直接停止程序**，完全避免了因为频繁报错而造成的程序员心理问题；同时，开启`happy`选项后将**禁用调试模式**。
- `hex`：如果在开启调试模式的情况下启用该选项，将使调试信息的数字变为16进制输出。
- `o2`：对Sephirah程序开启O2优化。开启后，解释器将忽略50%的语句，使得程序的运行速度**增加一倍**。
- `o3`：对Sephirah程序开启O3优化。开启后，解释器将忽略75%的语句，使得程序的运行速度**增加三倍**。
- `read`：启用该选项后，才可开启输入缓冲区并使用SEX “`R`”（见下文），否则解释器会忽略它。
- `mute`：禁用一切输入输出，包括调试输出。

### 新的操作符

Sephirah扩展增加了两个新的移动指令：`l`和`r`，分别对应指针向左/向右**移动两格**。

Sephirah扩展还增加了两个新的数据结构——**上单元格（Upper Cell）**和**输入缓冲区（Input Buffer）**。

- 上单元格相当于全局变量，可以存储于普通单元格相同的数据，且可以在指针位于任意处时（除了丢弃指针时，见下文）访问。
- 输入缓冲区是一个队列，在程序开始时，解释器会要求用户输入并按顺序加入到缓冲区中。

Sephirah扩展所增加的Sephirah称为**Sephirah EXt（SEX）指令**。SEX指令与Sephirah类似，但无法存储在单元格内。以下是SEX指令的功能：

- **SEX “`A`”**：人类可读输出。类似Sephirah “`a`”，但当单元格内存储的是数字时，SEX “`A`”会直接输出该数字；若单元格内存储的是Sephirah，则会直接输出该Sephirah。例如当单元格内存储的是`67`时，Sephirah “`a`”会输出ASCII字符`C`，但SEX “`A`”会输出`67`。
- **SEX “`S`”**：输出一个空格。
- **SEX “`L`”**：输出一个换行符。
- **SEX “`T`”**：输出一个制表符。
- **SEX “`R`”**：输入。在开启`read`运行选项的前提下，每次调用SEX “`R`”，都会从输入缓冲区载入一个字符，并将其ASCII码值加到当前单元格上，随后使这个字符出队。
- **SEX “`x`”**：将当前单元格与左侧单元格的值交换（如果没有左侧单元格则扩展纸带），并保持指针位置不变。
- **SEX “`*`”**：如果左侧单元格内是Sephirah，则对当前单元格运行这个Sephirah；否则忽略。
- **SEX “`&`”**：将左右两侧单元格内的数字加到本单元格内，同时将左右两侧单元格归零。如果当前/左右两侧单元格内有任一存储的是Sephirah，就会出现报错；如果缺少左侧和/或右侧的单元格，只操作存在的单元格。
- **SEX “`~`”**：如果当前单元格是数字，则将数字按位取反。
- **SEX “`$`”**：以当前的金价（单位为美元）作为随机种子，生成随机数并加到当前单元格内。如果金价波动较大，程序员们应该庆幸自己写的随机数生成器更加难以破解了。
- **SEX “`u`”**：如果上单元格存储着Sephirah，则运行该Sephirah。
- **SEX “`p`”**：如果上单元格存储着数字，则将数字加1，否则报错。
- **SEX “`m`”**：如果上单元格存储着数字，则将数字减1，否则报错。
- **SEX “`z`”**：如果上单元格存储着数字，则归零，否则报错。
- **SEX “`[`”**：上单元格循环开始标记。
- **SEX “`]`”**：若上单元格不是0也不是Sephirah “`0`”，跳转至上一个SEX “`[`”所在的行。
- **SEX “`e`”**：让程序在此处延迟12小时。
- **SEX “`!`”**：跳转到程序的第一行。
